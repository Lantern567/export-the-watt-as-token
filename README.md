# Waking the world's untapped mega-energy resources through the global token economy

A *Perspective*-style manuscript (target: ***Nature Energy***) and its reproducible evidence base,
arguing that for a large class of **stranded clean-energy resources** — remote mega-dams, desert
wind-and-solar export hubs, and structurally curtailed renewable fleets — the highest-value export
is **AI inference (tokens) over optical fibre**, not electrons over lossy ultra-long-distance
transmission. Per source kilowatt-hour, a token can embed roughly **10–1,000×** the value density of
an electron or of aluminium. The analysis is organised around a **global project portfolio**, **AI
demand scenarios**, **hourly global temporal matching**, and a realistic **chip constraint** — not a
single dam (Yarlung Tsangpo is one row of the portfolio, the extreme case).

> ⚠️ **Working draft of an unpublished manuscript.** Numbers are presented as ranges generated by the
> `analysis/` pipeline; several citations still need replacement with primary literature before submission.

## Reproducing the analysis and figures

```bash
pip install matplotlib numpy pandas scipy requests cartopy   # cartopy only for Fig. S1 map
python analysis/portfolio_demand.py      # M1 -> data/portfolio.csv, portfolio_demand_results.json
python analysis/lifecycle_cost.py        # M4 -> data/lifecycle_results.json (life-cycle value, Fig. 2)

python analysis/temporal_matching.py     # M2 -> needs internet on first run (Open-Meteo ERA5), then cached

```

## Key display items

- **Fig. 1** — three export pathways from one stranded-energy site (electrons / aluminium / tokens).
- **Fig. 2** — full life-cycle cost and value per source kWh (gross value · life-cycle cost · net value added; token wins net by ~50–170×).
- **Fig. 3** — global stranded resource base vs AI demand scenarios, in energy and token terms.
- **Fig. 4** — *signature*: hourly global temporal matching; a distributed portfolio follows the always-on token load with ~6× less storage than one site.
- **Fig. 5** — the binding constraint is chips, capital and ramp, not watts.
- **Box 1** — the tiered candidate-project portfolio table.

## Relationship to "Desert power for the AI era" (Zhu et al., *Nexus* 2026)

That paper (`mmc2.pdf`) optimises off-grid desert wind-solar-storage to firm **each site** to 24/7. We
adopt its screening method and cite it as supply-side proof, and add what it does not cover:
(i) the **value-density** reframing, (ii) **demand-side global temporal matching** with a distributed
portfolio, and (iii) the **chip constraint**.
